## Overview

The **Customer Churn Analysis Dashboard** is an interactive Power BI project designed to analyze customer retention and churn trends. It helps businesses understand customer behavior by visualizing key performance indicators (KPIs), contract distribution, tenure-based churn rates, customer risk categories, and monthly charge patterns.

The dashboard enables stakeholders to identify customers at higher risk of churn and supports data-driven decision-making for improving customer retention.


## Features

* Interactive customer retention overview
* Churn rate analysis
* Customer segmentation by risk type
* Contract-wise churn analysis
* Tenure-based churn comparison
* Monthly charges analysis for retained and churned customers
* Existing vs. New customer comparison
* Online Security and Online Backup service analysis


## Dashboard Insights

* Customers with **Month-to-Month contracts** contribute the highest number of churned customers.
* Customers in the **0–6 months tenure** group have the highest churn rate.
* The dashboard categorizes retained customers into **Normal** and **High Risk** groups.
* Monthly charges are analyzed to compare retained and churned customers.
* Customer type analysis compares **Existing** and **New Customers**.
* Service adoption (Online Security and Online Backup) is visualized alongside monthly charges.

## Business Objective

The objective of this project is to:

* Monitor customer churn performance.
* Identify customer segments with higher churn risk.
* Analyze churn across contract types and tenure bands.
* Support strategic customer retention initiatives using interactive visual analytics.
